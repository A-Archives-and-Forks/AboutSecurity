## 漏洞描述

深信服 SSL VPN 存在注入漏洞（CNVD-2020-48679），影响 SSL VPN 7.6.7 及以下版本。深信服官方公告指出，攻击者可利用该漏洞获取 SSL VPN 设备控制权限；部分安全机构（360CERT 等）在通告中进一步描述为 SSL VPN 某接口的 url 参数存在注入，可导致命令执行。CNVD 记录描述为"命令执行/注入"。官方已在 7.6.7 之前的版本上发布修复补丁，升级到高版本不受影响。

**注意**：本条目只覆盖 CNVD-2020-48679（SSL VPN 注入）；深信服 EDR、aTrust、升级维护工具等产品漏洞各自独立编号，不要合并。公开资料未披露完整 PoC 细节，验证以官方补丁版本核对为主。

## 影响版本

- 深信服 SSL VPN 7.6.7 及以下版本（官方公告）
- 高版本不受影响，通过升级 SSL VPN 版本可修复

## 前置条件

- 目标为暴露在外的深信服 SSL VPN 设备（常见登录入口 /por/login_psw.csp）

## 验证方法

1. 识别目标为深信服 SSL VPN（登录页特征、/por/login_psw.csp）
2. 在授权范围内对官方公告涉及的 url 参数类接口做注入探测（差异响应/时间盲注）
3. 结合设备版本与官方补丁核对受影响范围
4. 由于公开 PoC 细节有限，不应在未授权目标上直接尝试命令执行 payload

## 指纹确认

```bash
curl -s "http://target/por/login_psw.csp" | grep -iE "sangfor|深信服|sslvpn"
```

## 修复建议

1. 升级 SSL VPN 至 7.6.7 以上版本并安装最新安全补丁
2. 限制 SSL VPN 管理接口仅内网可达
3. 开启设备日志审计，关注异常 url 参数请求
