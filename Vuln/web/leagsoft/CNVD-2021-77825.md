## 漏洞描述

深圳市联软科技股份有限公司企业移动管理平台（Leagsoft EMM）存在文件上传漏洞（CNVD-2021-77825）。CNVD 记录显示攻击者可利用该漏洞上传恶意文件，存在进一步获取服务器权限的风险。CNVD 未公开具体受影响接口与 PoC 细节，本条目为公告级记录，不包含未经验证的利用步骤。

**注意**：本条目只覆盖 CNVD-2021-77825（Leagsoft EMM 文件上传）；联软安全数据交换系统、入网身份认证系统的漏洞各自独立编号，不要合并。

## 影响版本

- Leagsoft EMM（企业移动管理平台），CNVD 未披露精确版本

## 前置条件

- 目标为联软 EMM 企业移动管理平台
- CNVD 未披露是否需要认证，实际核验前需先确认授权边界

## 验证方法

1. 先识别目标是否为联软 EMM（登录页/API 特征、厂商版权信息）
2. 依据 CNVD 记录，重点排查文件上传/导入类功能点（头像、附件、应用包上传等）
3. 在授权范围内上传测试文件，观察是否可上传非白名单类型文件及存储路径是否可预测
4. 由于公开细节有限，应以厂商补丁和资产自查为准，不要盲扫未授权目标

## 指纹确认

```bash
curl -s "http://target/" | grep -iE "leagsoft|联软|emm"
```

## 修复建议

1. 联系厂商获取补丁并升级
2. 对上传接口增加类型白名单、内容校验与随机化存储路径
3. 限制管理端/上传入口仅内网可达
