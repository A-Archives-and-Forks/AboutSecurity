## 漏洞描述

泛微 E-cology10（E10）存在未授权远程代码执行漏洞（QVD-2026-14149）。奇安信 CERT 通告显示，未经身份验证的远程攻击者可向特定接口发送恶意请求，在目标服务器上执行任意代码（可结合文件上传/文件写入类行为，或通过 file 相关接口/参数触发）并获取服务器权限；CVSS 评分约 9.8（CRITICAL）。官方已发布修复补丁（对应版本 v20260312 及之后）。

**注意**：
- 该漏洞 PoC 未公开披露（截至本条目编写），本条目为公告级记录，不包含未经验证的利用步骤。
- 本条目只覆盖 E-cology10 QVD-2026-14149；E-Cology 8.0-9.0 getFileViewUrl SSRF、eteams 越权等漏洞各自独立编号，不要合并。

## 影响版本

- 泛微 E-cology10，补丁版本早于 v20260312（以官方补丁版本核对为准）

## 前置条件

- 目标为暴露在外的泛微 E-cology10
- 未授权利用（官方通告确认）

## 验证方法

1. 识别目标是否为 E-cology10（登录页 /login.jsp、版本信息）
2. 核对补丁版本是否低于 v20260312
3. PoC 未公开，评估时优先核对版本与补丁状态，不盲目构造未公开接口请求
4. 若确认受影响，联系厂商获取补丁并升级

## 指纹确认

```bash
curl -s "http://target/login.jsp" | grep -iE "weaver|ecology|泛微"
```

## 修复建议

1. 升级至官方修复版本（v20260312 及之后）
2. 在修复前限制 E-cology10 外网暴露面
3. 监控应用服务器异常进程/命令执行行为
